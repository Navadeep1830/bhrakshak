Testing connection…
Start the server on the command-center laptop (npm run dev) and enter its Wi-Fi address here — phone and laptop must be on the same Wi-Fi / hotspot.

Find the laptop's IP with ipconfig (Windows) or ip a (Linux/Mac).
If it won't connect: allow Node.js through the Windows firewall (network type: private), and make sure you're typing the laptop's IP — not 127.0.0.1 (that's the phone itself).
