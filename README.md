# BhuRakshak (भूरक्षक)

**AI-Based Early Warning and Landslide Risk Monitoring System in NER — SIH26001**

*From reactive response to predictive protection.*

4-layer early warning: **WHERE** landslides happen (susceptibility) → **WHEN**
(rainfall nowcast + I-D thresholds + calibrated ML, fused with hysteresis) →
**IS IT MOVING** (Sentinel-1 InSAR creep anomalies) → **WHO'S IN THE WAY**
(exposure, response priority queue, road detours).

## One command

```bash
cp .env.example .env
make up          # boots postgres(postgis+timescale), redis, mosquitto, minio,
                 # martin tiles, api, worker+beat+flower, dashboard, field pwa
make migrate     # alembic schema incl. hypertables
make seed        # 4 pilot districts -> ~5km hex-grid zones clipped to boundaries
```

## Demo flow (90 seconds)

```bash
make demo        # realistic seed + storm injection
```
or click **"⛈ Inject Monsoon Cell (Demo)"** on the dashboard bottom-left:
zones escalate amber→red, alerts fire on the live ticker, SMS templates render
in 8 languages (`/api/v1/alerts/preview-fire`), road flips to blocked.

Pilot districts: **Aizawl (MZ), East Khasi Hills (ML), Noney + Imphal West (MN),
Gangtok (SK)** — zone codes like `ML-EKH-004`.

## Layout

```
apps/api       FastAPI · async SQLAlchemy 2.0 · pydantic v2 · JWT refresh rotation
               RBAC (admin/district_admin/field_official/citizen) · slowapi limits
apps/worker    Celery beat: rainfall poll 15m · risk recompute 15m · seismic 1h
               MQTT bridge for sensors/#  →  sensor_readings hypertable
apps/dashboard Next.js 14 · TS · Tailwind · MapLibre GL · ECharts (SHAP waterfall)
apps/field-pwa Vite PWA · Workbox offline · Dexie queue · idempotent batch sync
ml/            ingest (dem/inventory/weather) · features · models A–E · backtest
               registry. Leave-one-district-out spatial CV. Offline synthetic mode.
infra/         docker-compose · martin tile config · mosquitto · minio init
scripts/       seed.py (hex grid) · seed_realistic.py (demo state)
demo/          storm_injector.py · sensor_simulator.py · backtest fixture
docs/          architecture.md · runbook.md · model-cards/
```
