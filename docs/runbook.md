# BhuRakshak Runbook

## 0. Prerequisites

- Docker + docker compose plugin (16 GB RAM laptop is enough; Postgres capped at 1.5 GB)
- Ports used: 3000 (dashboard), 5173 (pwa), 8000 (api), 3001 (martin), 5555 (flower),
  5433 (postgres), 6380 (redis), 1883 (mqtt), 9000/9001 (minio)

## 1. Cold start (one command)

```bash
cp .env.example .env
make up        # builds backend image, starts all services in background
make migrate   # alembic 0001_initial: tables + postgis + hypertables
make seed      # hex-grid zones, RBAC users, roads, i18n, model registry row
```

Verify:

```bash
curl localhost:8000/health                                  # {"status":"ok"}
docker compose -f infra/docker-compose.yml ps               # all healthy
curl -s localhost:3001/zones/7/60/30.pbf | wc -c            # non-zero = tiles live
```

Logins seeded: admin@bhrakshak.in/Admin@123 · dc.aizawl@…/District@123 ·
field.noney@…/Field@123 · citizen@bhrakshak.in/Citizen@123.

## 2. Demo state & the money shot

```bash
make demo    # seed_realistic (reports, blocked NH) + storm over East Khasi Hills
```

Dashboard flow (90 s): open :3000 → click **⛈ Inject Monsoon Cell** → zones go
amber→red on the map, ticker shows alerts, KPI bar counts up → click a red zone
→ SHAP "Why this risk" waterfall + rainfall vs threshold chart.
Multilingual SMS proof: `POST /api/v1/alerts/preview-fire?zone_id=…&lang=hi`.
PWA offline proof (:5173): DevTools → Network → Offline → submit report →
"Saved — will sync" → back Online → auto-sync → verify in dashboard reports queue.

## 3. Day-2 operations

| Task | Command |
|---|---|
| Tail logs | `make logs` |
| Recompute risk now | `docker compose -f infra/docker-compose.yml exec worker celery -A worker.celery_app call tasks.recompute_risk` |
| Sensor sim (MQTT→DB) | `python demo/sensor_simulator.py --host localhost --port 1883` |
| Storm via CLI | `python demo/storm_injector.py --district Aizawl --peak 60` |
| New migration | `make revision m="add foo"` then `make migrate` |
| ML pipeline offline | `cd ml && make data && make train-susceptibility` |
| Tests | `make test` (needs stack up; skips cleanly if DB unreachable) |

## 4. Troubleshooting

- **Martin returns empty tiles** → migrations not applied or `risk_cells.geom` NULL:
  run `make migrate && make seed`; the seed mirrors zone geometry into risk_cells.
- **Postgres won't start / timescale license error** → `make nuke` wipes volumes, retry.
- **Port clash** (local pg/redis) → we use 5433/6380 deliberately; if still busy,
  change ports in `.env` + compose port mappings only.
- **Dashboard shows FIXTURE MODE badge** → API down or CORS; check `make logs api`,
  confirm `NEXT_PUBLIC_API_URL=http://localhost:8000`.
- **Celery beat not firing** → Flower (:5555) should show beat uptime; else restart
  `beat` service. Tasks log under worker service.
- **WS ticker silent** → heartbeats every 15 s mean healthy; no heartbeats = redis pubsub
  unreachable (check REDIS_URL).

## 5. Finale checklist (venue day)

1. **T−24 h**: `make nuke && make up && make migrate && make seed && make demo` from scratch.
2. Run the dashboard demo twice end-to-end; screenshot metrics for slides must come
   from `demo/backtest_fixture.json` regenerated by `ml/models/backtest.py`.
3. **Backup plan A (WiFi dead)**: everything is local docker + fixture mode — nothing
   external is required at runtime (Open-Meteo calls fall back to synthetic).
4. **Backup plan B (laptop dies)**: second machine runs the same 4 commands; keep a
   screen recording of the 6-minute script as last resort.
5. **API rate-limit**: slowapi caps login at burst rates — demo logins are fine;
   if hammering previews in rehearsal, restart api container to clear limits.
6. Freeze versions night before: do NOT `npm install` new packages on stage day.

## 6. Security notes (say these out loud in Q&A)

- Refresh-token rotation with family revocation on reuse (see `apps/api/app/api/v1/auth.py`).
- Phone numbers stored hashed (DPDP data-minimization posture); bcrypt password hashing.
- RBAC enforced per-route (`require_roles`) — citizens cannot verify reports; field
  officials cannot fire demo storms; tests cover denial paths.
